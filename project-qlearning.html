Projects / Reinforcement Learning

Q-Learning from Scratch

Implemented tabular Q-learning in Python from scratch using OpenAI Gym's Taxi-v3 environment, with a browser-based FrozenLake interactive demo using the same algorithm.

500 State Space (Taxi-v3)
10K Training Episodes
ε-greedy Exploration Strategy
Overview

Built a complete tabular Q-learning agent without high-level RL libraries. The agent learns to navigate OpenAI Gym's Taxi-v3 environment — picking up passengers and dropping them off while minimizing timesteps and avoiding illegal actions.

The same core algorithm (Q-table initialization, ε-greedy action selection, and Bellman updates) powers the interactive FrozenLake demo below, making the exploration/exploitation tradeoff tangible on a 4×4 grid.

Goals
  • Understand reinforcement learning fundamentals from first principles.
  • Build Q-table updates manually using the Bellman equation.
  • Compare exploration strategies with different epsilon values.
  • Visualize training dynamics and learned policies.
Results
  • Trained agents on Taxi-v3 over 10,000 episodes with ε = 0.1 and ε = 0.3.
  • Agents consistently achieve positive median rewards after convergence.
  • FrozenLake demo reaches high success rates within 5,000–8,000 episodes.
  • Demonstrated clear policy improvement from random to greedy exploitation.
Key Learnings
  • Exploration vs. exploitation tradeoff — higher ε explores more but learns slower.
  • Learning rate (α) and discount factor (γ) strongly affect convergence speed.
  • Reward shaping matters — sparse rewards make early training difficult.
  • Tabular methods scale poorly but build essential intuition for deep RL.

The Algorithm

Each step updates the Q-value for state s and action a using the temporal-difference target:

Q(s, a) ← Q(s, a) + α [r + γ maxa' Q(s', a') − Q(s, a)]
Exploration vs. Exploitation

During training, actions are selected via ε-greedy policy: with probability ε the agent explores randomly; otherwise it exploits the best-known action (argmax of the Q-row). Lower ε converges faster but risks suboptimal policies.

Environment Details

Taxi-v3: 500 discrete states, 6 actions (N/S/E/W + pickup/dropoff). +20 for successful dropoff, −1 per timestep, −10 for illegal pickup/dropoff.

FrozenLake: 16 states, 4 actions. Reach goal (G) from start (S) without falling in holes (H). Used for the interactive demo below.

Before & After Training

Before Training

Random action selection wanders the grid, frequently falling into holes or taking unnecessarily long paths. The agent has no memory of which actions lead to reward.

After Training

After Q-learning, the agent follows the learned policy — navigating directly toward the goal while avoiding holes. Consistent success across episodes.

Technical Challenges
  • Implementing the Bellman update correctly — using max Q(s', a') over the next state, not the current state.
  • Balancing exploration so the agent discovers the goal without wasting episodes in holes.
  • Taxi-v3's large state space (500 states × 6 actions) requires thousands of episodes to converge.
  • Porting the Python algorithm to JavaScript while preserving identical update logic for the browser demo.
Future Improvements
  • Add SARSA and expected-SARSA for on-policy comparison.
  • Implement slippery FrozenLake dynamics for added difficulty.
  • Deploy Taxi-v3 visualization via a Streamlit or Hugging Face Space backend.
  • Extend to function approximation with a neural network (DQN) for larger state spaces.
