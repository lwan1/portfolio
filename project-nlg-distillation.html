NLG & Knowledge Distillation

Implemented five decoding algorithms from scratch on GPT-2, then distilled summarization ability from Qwen2.5-1.5B-Instruct into a 124M-parameter student model on CNN/Daily Mail.

+19% ROUGE-1 Improvement
1K Teacher Summaries
5 Decoding Algorithms
Overview

This assignment spans two core NLP topics: decoding strategies for text generation and knowledge distillation for task-specific fine-tuning. In Part 1, five token-selection algorithms — greedy, vanilla sampling, temperature, top-k, and top-p — were implemented inside a custom decode() wrapper and evaluated on ROCStories story continuation with GPT-2.

In Part 2, Qwen2.5-1.5B-Instruct served as a teacher to generate 1,000 pseudo-labeled summaries on CNN/Daily Mail articles. A GPT-2 student was fine-tuned on teacher outputs (with prompt tokens masked via -100) and evaluated against human gold summaries using ROUGE.

Goals
  • Implement greedy, vanilla, temperature, top-k, and top-p decoding from logits to tokens.
  • Quantify the fluency–diversity tradeoff using perplexity, CoLA fluency, and n-gram diversity.
  • Build a teacher–student summarization pipeline with instruction-tuned and completion-style LMs.
  • Fine-tune GPT-2 on teacher-generated pseudo-labels with masked language modeling.
  • Measure summarization quality via ROUGE-1/2/L on 1,000 validation articles.
Results
  • Top-p decoding achieved the best balance: perplexity 11.66, fluency 0.75, trigram diversity 0.94.
  • Greedy decoding maximized fluency (0.79) but near-zero diversity (0.02) — outputs were nearly identical.
  • ROUGE-1 improved from 0.193 (baseline) to 0.230 (distilled) — a +19% relative gain.
  • ROUGE-2 improved from 0.033 to 0.057 (+73%) — the largest relative metric gain.
  • Training converged in 3 epochs (~10 min on T4): final train loss 2.48, val loss 3.01.
Key Learnings
  • Decoding strategy matters as much as model weights — same GPT-2 produces radically different text.
  • Vanilla sampling maximizes diversity but yields incoherent output (perplexity 73.95, fluency 0.34).
  • Zero-shot GPT-2 with a TL;DR prompt alone cannot summarize news articles meaningfully.
  • 1,000 teacher pseudo-labels materially improve a 124M model without soft-logit distillation.
  • ROUGE measures lexical overlap, not faithfulness — distilled summaries still hallucinate facts.

Part 1 — Decoding

Custom decode() with KV-cache handles batched generation. Each strategy selects the next token differently: greedy takes argmax; sampling draws from the full softmax; temperature scales logits before softmax; top-k masks non-top-k logits; top-p truncates by cumulative probability mass.

Part 2 — Distillation

Teacher uses chat templating with a system prompt; student uses completion-style article\nTL;DR: formatting. Only summary tokens contribute to the loss — article prompt tokens are masked with label=-100. Generation uses top-p=0.9, temperature=1.0, max 100 new tokens.

Technical Challenges
  • GPU memory on T4 — holding Qwen 1.5B, GPT-2, and CoLA fluency model required deleting CoLA before fine-tuning, plus fp16 and gradient checkpointing.
  • Tokenizer format mismatch — completion-style TL;DR for GPT-2 student vs. chat template for Qwen teacher.
  • Long articles truncated at 1,024 tokens, losing tail content relevant to summaries.
  • GPT-2 lacks native summarization ability — requires prompt engineering and distillation to be useful at all.
  • ROUGE rewards word overlap, not factual correctness — hallucinations can still score reasonably.
Hyperparameters
  • Fine-tuning: 3 epochs, lr=2e-5, batch=4, gradient accumulation=4, warmup=100 steps.
  • Generation: top-p=0.9, temperature=1.0, max 100 new tokens.
  • Decoding eval: max 100 tokens, 10 generations per prompt on ROCStories test set.
  • Teacher: Qwen2.5-1.5B-Instruct (28 layers, 1536 hidden). Student: GPT-2 (124M params).
Future Improvements
  • Scale to full CNN/Daily Mail train set (10K+) with a larger teacher (7B+).
  • Use true soft-label distillation via KL divergence on teacher logits.
  • Add factuality metrics (NLI-based or entity overlap) beyond ROUGE.
  • Beam search or constrained decoding for summarization quality.
  • LoRA/QLoRA for efficient fine-tuning of larger student architectures.
Technologies
  • PyTorch, HuggingFace Transformers.
  • GPT-2 (124M), Qwen2.5-1.5B-Instruct (teacher).
  • ROCStories, CNN/Daily Mail, custom KD dataset.
  • ROUGE, perplexity, RoBERTa-CoLA fluency classifier.
  • Google Colab T4 GPU, TensorBoard logging.
