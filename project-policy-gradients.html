Deep RL & Policy Gradients

Implemented the REINFORCE policy-gradient algorithm in two settings: a discrete-action neural agent that balances CartPole, and a continuous-control CNN that learns to drive end-to-end from raw pixels in the VISTA simulator.

Overview

Unlike supervised learning, a reinforcement-learning agent gets no labels — only a stream of rewards. This project builds the policy gradient method from scratch, where a neural network is the policy: it maps observations directly to action probabilities and is nudged to make high-reward actions more likely.

Part 1 — CartPole: a feed-forward network balances a pole with two discrete actions. Part 2 — VISTA: a convolutional network outputs a continuous steering distribution, learning lane-following entirely inside a photorealistic, data-driven driving simulator.

Goals
  • Define agents as neural networks that output action distributions.
  • Implement a reusable Memory buffer of observations, actions, and rewards.
  • Compute normalized, discounted returns for credit assignment.
  • Derive the policy-gradient loss (reward-weighted negative log-likelihood).
  • Extend from discrete (softmax) to continuous (Gaussian) action spaces.
Results
  • The CartPole agent learns from a near-random policy to consistently balancing the pole for full-length episodes.
  • Reward climbs steadily over training episodes as the policy sharpens.
  • The VISTA driving agent learns to stay in-lane far longer than a random controller, judged by distance traveled before crashing.
  • The identical train_step + discounting code drives both agents — only the loss and model differ.
Key Learnings
  • Gradients are minimized on negative log-likelihood scaled by return — increasing the odds of good actions.
  • RL gradients are extremely noisy; global-norm gradient clipping is what keeps training stable.
  • Discrete actions use softmax cross-entropy; continuous actions use a Normal log-prob.
  • Reward shaping and normalization dramatically affect convergence speed.

The Algorithm

Policy gradients maximize expected return by scaling each action's log-probability by the return that followed it:

L(θ) = − Σt log πθ(at | st) · Rt

where the return Rt = Σk γk rt+k is the discounted, then normalized, future reward.

Discrete — CartPole

Observation: 4 floats (cart position, cart velocity, pole angle, pole angular velocity). The policy is Dense(32, relu) → Dense(2); logits become a categorical distribution sampled with tf.random.categorical. Loss is sparse_softmax_cross_entropy weighted by return.

Continuous — VISTA Driving

Observation: a cropped RGB camera image. A 4-layer CNN (swish) outputs a mean μ and σ defining a Normal distribution over curvature. Conversions bound it: μ = ⅛·tanh(·), σ = 0.1·sigmoid(·)+0.005. Loss is the Gaussian negative log-prob scaled by return.

Technical Challenges
  • High-variance gradients — addressed with reward normalization and global-norm clipping (clip value 2).
  • Sparse, delayed feedback: the agent only learns once an episode ends.
  • Moving from a categorical (discrete) to a Normal (continuous) policy changes the entire loss formulation.
  • Learning a driving policy directly from high-dimensional raw pixels, not engineered features.
  • Memory/compute pressure from image observations forced mini-batch sampling per update.
Hyperparameters
  • CartPole: Adam, lr 1e-3, γ 0.95, up to 500 episodes.
  • VISTA: Adam, lr 5e-4, max batch 300, max curvature ⅛, max σ 0.1.
  • Gradient clipping by global norm = 2.
  • Camera observation 200×320, cropped to a region of interest.
Future Improvements
  • Upgrade REINFORCE to PPO, TRPO, or A3C for sample efficiency and stability.
  • Add a learned baseline / value head to reduce gradient variance (actor-critic).
  • Reward shaping in VISTA — penalize distance from lane center, not just crashes.
  • Recurrent or attention-based controllers, plus image augmentation.
Technologies
  • TensorFlow 2 / Keras, TensorFlow Probability.
  • OpenAI Gym (CartPole-v1), VISTA data-driven simulator.
  • Convolutional policy network, Gaussian action head.
  • Browser demo: vanilla-JS physics + 2-layer policy net (manual backprop) + Chart.js.
